# Code of Conduct

Agent Action Surety is an open-source security project. We want technical disagreement to be rigorous while keeping collaboration respectful, specific, and safe.

## Expected behavior

- Discuss ideas, code, evidence, and threat models rather than attacking people.
- Welcome contributors across experience levels and explain project-specific constraints when reviewing work.
- Give reproducible security evidence where possible and clearly label assumptions or unverified claims.
- Respect privacy, embargoes, and coordinated disclosure for security vulnerabilities.
- Avoid harassment, discrimination, threats, doxxing, spam, and deliberately disruptive behavior.

## Security-sensitive discussion

Do not publish an undisclosed exploit, credential, private key, personal data, or bypass recipe in a public issue or pull request. Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Enforcement

Project maintainers may edit or remove abusive, unsafe, off-topic, or disclosure-breaking content and may temporarily or permanently restrict participation when necessary to protect contributors or users.

Report conduct concerns privately to `contact@nymrel.com`. Reports should include enough context for maintainers to assess the event without unnecessarily redistributing sensitive material.

Maintainers will evaluate reports in good faith, minimize disclosure of reporter identity, and document any project-level action that materially changes contribution access or policy.
